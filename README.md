# account-manage

## Getting Started

1. Clone 專案後進入資料夾：

   ```sh
   git clone <repo-url>
   cd vue3-project
   ```

2. 安裝套件：

   ```sh
   npm install
   ```

3. 設定環境變數：在專案根目錄新增 `.env` 檔案（內容另外提供），需包含以下變數：

   ```
   VITE_API_BASE_URL=
   VITE_INTERVIEWER_NAME=
   ```

4. 啟動開發伺服器：

   ```sh
   npm run dev
   ```

   啟動後預設可用瀏覽器開啟 `http://localhost:5173` 查看。
